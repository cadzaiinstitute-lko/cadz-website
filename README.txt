CAD-Z Website Starter — Version 1

Preview: extract this ZIP and open index.html in Chrome.
Included: responsive website, course cards, enquiry form that pre-fills WhatsApp, contact details, PWA manifest and offline cache.

Important:
- This is a front-end prototype, not a published website.
- The form opens WhatsApp; the visitor must review and send it.
- There is no secure admin login, shared database, student login, payments, or central attendance/fee records yet.
- Do not use a browser-only prototype as an official student database.
- Career support is described without guaranteeing employment.
- PWA/offline installation requires hosting over HTTPS or localhost; opening as a file does not enable service workers.
